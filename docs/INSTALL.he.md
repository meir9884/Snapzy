# Snapzy בעברית — התקנה

גרסת קוד פתוח מותאמת המבוססת על Snapzy, עם ממשק עברי מלא ושמירת האפשרות לבחור English בהעדפות ← כללי ← שפת היישום.

1. יש לפתוח את Snapzy-Hebrew.dmg.
2. יש לגרור את Snapzy.app לתיקיית Applications. אם מותקנת גרסה קודמת, יש לסגור אותה ולשמור עותק שלה לפני החלפתה.
3. יש להפעיל את Snapzy מתיקיית היישומים ולהעניק את הרשאות הצילום הנדרשות. מיקרופון ומצלמה נדרשים רק לשימוש בתכונות המתאימות.

החבילה נחתמה בחתימה מקומית (ad hoc). היא אינה חתומה בתעודת Developer ID ואינה מאושרת נוטריונית בידי Apple. macOS עשוי לחסום את פתיחתה; במקרה כזה יש לפעול ידנית לפי אפשרויות האבטחה של macOS ורק לאחר בדיקת המקור.

הגרסה מתחילה בעברית בהפעלה הראשונה. בחירת השפה נשמרת, והחלפתה חלה לאחר הפעלה מחדש. ניתן לבחור גם בשפת המערכת.

כדי למנוע החלפה אוטומטית בגרסה המקורית ואובדן העברית, העדכון האוטומטי מהפרויקט המקורי אינו מופעל בגרסה זו. פעולת בדיקת העדכונים פותחת את עמוד הגרסאות של ה־Fork:
